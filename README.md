# Musical Ensemble Management System (MEMS)

A Java console application for managing music ensembles (Orchestra / Jazz Band) and their musicians, with full undo/redo support.

## Tech Stack
Java, OOP, Command Pattern, Memento Pattern, Factory Pattern, Strategy Pattern

## Core Features
- Create / set current ensemble
- Add, modify, delete musicians
- Show current ensemble / all ensembles
- Change ensemble name
- Undo / redo / show undo-redo list
- Input validation and error handling
